Design notes for review (not part of the app)

  1. The app is the source of truth, Google Calendar is the mirror. Appointments come from the contact book (date + time + address); the calendar screen just draws them.
  2. Push creates a Google Calendar event (title "Appt · Loretta Nelson · Hideaway", location = address, description = phone + blurb). The event id is stored on the contact, so editing the appointment later updates the same event instead of making a duplicate.
  3. Unsynced vs synced: orange = not in Google Calendar yet. Push one from its drawer, or everything at once with "Push N unsynced". Option later: push automatically on save.
  4. Busy blocks are read-only events pulled from your Google Calendar so you can see conflicts before booking. Could be dropped if noisy.
  5. Which calendar to push to is a setting (top right). A dedicated "ArmorTex Appointments" calendar keeps work separate and can be shared with reps.
  6. Phones get an agenda list instead of the week grid. Month view is on the list but not mocked yet.
